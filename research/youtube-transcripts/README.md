# YouTube Transcripts

This directory contains YouTube video transcripts collected from experts researching AI-powered SEO content production.

The transcripts will be used to analyze:

- AI-assisted content workflows
- Semantic SEO
- Topical authority
- Content scaling strategies
- Search quality and E-E-A-T
- SEO automation and AI tools

Each transcript file will include:
- Video title
- Video URL
- Publication date
- Transcript
- Key insights
