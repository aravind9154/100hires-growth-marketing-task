# Research Methodology

## Objective

Collect and analyze content from leading AI SEO practitioners.

## Expert Selection Process

Experts were selected based on:

- Active publishing frequency
- Industry reputation
- Demonstrated SEO experience
- AI and content production expertise

## LinkedIn Collection

1. Identified recent posts from each expert.
2. Reviewed posts published during the target period.
3. Extracted key insights.
4. Organize findings by author.

## YouTube Collection

1. Identified relevant videos.
2. Retrieved transcripts.
3. Reviewed and summarize content.
4. Extracted recurring concepts and workflows.

## Tools Used

- GitHub
- ChatGPT
- Claude Code / Codex
- YouTube transcript tools
- Manual validation
